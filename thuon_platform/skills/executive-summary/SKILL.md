# Executive Summary Skill

## Core question

What must the decision-maker do, on what evidence, with what risk?

## Structure (one page max)

1. **Bottom line** — one sentence. Recommendation + magnitude.
2. **Why this matters** — 2–3 sentences, business consequence in numbers.
3. **Three supporting points** — bulleted, each with [A]/[B]/[C] grade.
4. **Decision required** — what ask, by when.
5. **Top risk** — single most likely failure mode plus mitigation.
6. **Appendix pointer** — where full analysis lives.

## Discipline

- No bullet > 25 words.
- No claim without grade.
- No weasel words ("appears to", "may potentially").
- Recommendation in the first sentence.

## Falsifier

If any supporting point is grade [C] only, the recommendation must soften
(differ, don't decide).
